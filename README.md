# Netflix Content Analysis Dashboard

An interactive Tableau dashboard that explores Netflix's movie and TV show catalog. The dashboard highlights content distribution, ratings, genres, release trends, and country-wise availability to make the catalog easier to explore.


## Dashboard Preview

![Netflix Dashboard](d:\Netflix.png)

## Dashboard Highlights

- **Content details:** View information about a selected title, including type, title, duration, rating, release year, date added, genre, and description.
- **Content by country:** Explore the geographic distribution of Netflix titles across countries.
- **Ratings breakdown:** Compare the number of titles across rating categories.
- **Movies vs. TV Shows:** See the proportion and count of movies and TV shows in the catalog.
- **Top 10 genres:** Identify the most represented genre categories.
- **Content added over time:** Explore the catalog's yearly trend, separated into movies and TV shows.

## Tools Used

- **Tableau** — dashboard design, data visualization, and interactive analysis
- **Netflix titles dataset** (`netflix_titles`) — data source used in the workbook

## Workbook Contents

The Tableau workbook includes worksheets for:

- Date added
- Description
- Duration
- Genre
- Movies & TV shows distribution
- Rating
- Ratings
- Released year
- Top-10 genres
- Total movies & TV shows by countries
- Total movies & TV shows by years

These sheets are combined into the **Netflix** dashboard.

## How to View

1. Download or clone this project repository.
2. Open `Book1.twb` in Tableau Desktop.
3. If Tableau prompts for a missing data connection, reconnect it to the `netflix_titles` dataset.
4. Open the **Netflix** dashboard and interact with the visualizations to explore the data.

## Purpose

This project demonstrates dashboard-building and data-visualization skills, with an emphasis on presenting catalog information through clear, interactive visuals.
